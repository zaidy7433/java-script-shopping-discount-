# 🛍️ JavaScript Shopping Discount Calculator

A simple JavaScript project that calculates shopping discounts based on the purchase amount. It uses conditional statements (`if-else`) to determine the discount.

## 🌐 Live Demo
[View Shopping Discount Project](https://zaidy7433.github.io/java-script-shopping-discount-/)

## ✨ Features
- Takes shopping amount from the user.
- Applies a 15% discount on purchases above Rs. 5000.
- Applies a 5% discount on other purchases.
- Uses JavaScript conditional statements.
- Displays discount messages using alerts.

## 🛠️ Technologies Used
- HTML5
- JavaScript

## 📚 Concepts Learned
- Variables (`var`)
- `prompt()`
- `if-else` statements
- Comparison operators
- `alert()`
